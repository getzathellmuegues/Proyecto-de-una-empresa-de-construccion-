# Proyecto de software para una empresa de construcción

Desarrollar un sistema para gestionar clientes, obras, materiales, empleados y pedidos, mejorando el control de recursos y proyectos. Se emplearán Git y GitHub para administrar cambios y facilitar el mantenimiento. El proyecto pertenece a la formación en Análisis y Desarrollo de Software del SENA.

## Versión inicial
Este repositorio contiene una página web demostrativa para presentar la empresa y registrar obras de ejemplo en el navegador.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: interacción básica para agregar obras de ejemplo.
- `.gitignore`: archivos que Git debe ignorar.

## Cómo abrir el proyecto
1. Descarga o descomprime la carpeta.
2. Abre `index.html` con tu navegador.
3. Para modificar el proyecto, edita los archivos con un editor de texto o Visual Studio Code.

## Uso de Git
Desde Git Bash, dentro de esta carpeta, puedes ejecutar:

```bash
git init
git add .
git commit -m "Crear estructura inicial del proyecto"
```

Luego crea un repositorio vacío en GitHub y conecta el repositorio local siguiendo las instrucciones que GitHub te muestre.
